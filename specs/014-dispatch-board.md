## Goal
A local business with drivers (pharmacy, restaurant, florist) pastes its depot and today's stops. Noah says, per stop: *go before ~X*, *hold* (route forecast cut), or *no forecast flooding through the window*. A barricade list ranks forecast-flooded streets by time for city/county crews. This is the Replit "Small Business" app and the "who pays" answer: free for residents, dispatch boards for businesses, barricade lists for agencies.

## Non-goals
Logins, saved fleets, live vehicle tracking, multi-stop route optimization (TSP), billing, push alerts. These are roadmap items.

## Behavior
1. **Load once:** graph (C4 at `data/interim/graph.graphml`, else gunzip `fixtures/graph.graphml.gz`), active cycle (`NOAH_CYCLE` env, else C6 `demo_cycle`), that cycle's C5 as `seg_id → (t_uncertain, t_flood, name)`, AOI polygon.
2. **Blocking rule (identical to 006):** at departure hour *h*, an edge is blocked if `t_uncertain <= h + ROUTE_BUFFER_H`. Implemented as a networkx weight function returning `None` for blocked edges (no graph copies).
3. **Per depot:** for h = 0…18, run one single-source Dijkstra (`travel_time`) from the depot's nearest node. That's 19 runs total, regardless of the number of stops. States are sticky (no recession), so reachability only shrinks as *h* grows.
4. **Per stop verdict:**
   - outside AOI → `out_of_coverage`
   - reachable at every h → `no_forecast_flooding` (through the last valid time)
   - reachable at h=0 but not later → `go_before` with `go_before_utc` = the first unreachable hour
   - not reachable at h=0 → `hold` (route already forecast cut)
   Also return minutes at h=0 when reachable.
5. **Barricade list:** C5 segments with `t_flood`, grouped by street name + first flood hour, giving segment count, total length (m), and the local time. Sorted by time. Unnamed segments are grouped as "Unnamed road near <nearest named street>" or skipped if none. CSV export happens client-side.
6. **Sample data** (`web/data/dispatch_sample.json`), generated by a script from the graph: a depot plus 8 stops snapped to street intersections and labeled "<Street> at <Street>". No real homes or businesses. Mix: some on Helene-flagged streets, some dry, one outside coverage.
7. **Endpoints** (C13): `POST /dispatch` {`cycle`?, `depot` {label, lat, lon}, `stops` [{id, label, lat, lon}]} → {cycle, issue_time, valid_until, depot, stops: [{id, label, state, go_before_utc|null, minutes|null}]}; `GET /barricades?cycle=` → [{street, segments, length_m, first_flood_utc, state}].
8. **Page** `web/dispatch.html` (single file, MapLibre pinned like 009, dark): a stop list with verdict badges, a map with the flood layer at the selected hour and stop markers colored by verdict, a "Barricade list" tab + CSV download, and an editable stops textarea (`label, lat, lon` per line) prefilled from the sample. The API is the same origin, or `?api=`.
9. **Wording:** §5 frozen vocabulary + the new rows (CC5). Never "safe".
10. **Standalone run for testing** (until Priyanshu's `app.py` mounts the router): `uv run python -m noah.api.dispatch --serve` serves `/dispatch`, `/barricades` and `web/` on port 8001.
